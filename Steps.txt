Test ngrok BEFORE changing React

This is very important.

Suppose ngrok gives you:

https://abc123.ngrok-free.app

Open:

https://abc123.ngrok-free.app/accounts


Change React API URL

Now we deal with GitHub.

Your React code currently probably has something like:

axios.get("http://localhost:5000/accounts")

Change it to:

axios.get("https://abc123.ngrok-free.app/accounts")

Obviously replace abc123... with your actual ngrok URL.

For your CRUD:
==============
// GET
axios.get("https://abc123.ngrok-free.app/accounts");

// POST
axios.post("https://abc123.ngrok-free.app/accounts", data);

// PUT
axios.put(`https://abc123.ngrok-free.app/accounts/${id}`, data);

// DELETE
axios.delete(`https://abc123.ngrok-free.app/accounts/${id}`);

GitHub update
==============

From your React project:
